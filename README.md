# Jewellers Galleria

A responsive jewellery storefront for bridal, party-wear, and everyday collections in Lahore. The experience includes product discovery, category browsing, search, wish-list and cart interactions, and a direct WhatsApp ordering path.

## Live site

After GitHub Pages is enabled for this repository, the site is available at:

https://96frazali.github.io/jewellers-galleria/

## Preview

![Jewellers Galleria storefront preview](assets/jewellers-galleria-preview.png)

## Run locally

Open `index.html` in a browser, or start a local static server:

```bash
python -m http.server 5501
```

Then visit `http://127.0.0.1:5501/`.
